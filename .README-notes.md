# Additional notes

## Outputs

- `results/consensus/{sample}.{level}.bam`: consensus BAMs
- `results/vcf/{sample}.{level}.vcf.gz`: final calls
- `results/benchmark/summary.tsv` and `per_sample.tsv`
- `results/benchmark/plots/*.png`: sensitivity_by_vaf, ppv_by_vaf, fp_per_mb, fp_spectrum, informed_detection, family_sizes, duplex_yield
- `results/informed/{sample}.{level}.loci.tsv` and `.summary.tsv`: tumour-informed per-locus and sample-level calls (pooled in `benchmark/informed_summary.tsv`)
- `results/qc/fragments/*.stats.txt`: fragment-length distributions
- `results/qc/multiqc_report.html`

## Restarting from existing BAMs

If the raw FASTQs or other temporary files are gone but `results/bam/*.grouped.bam` and
`*.consensus.mapped.bam` exist, run only the downstream rules so Snakemake cannot reach back
to download or alignment:

```bash
# config.yaml: resume_from_bams: true and run_fastqc: false (raw FASTQs are gone)
ALLOWED="all prep_bed ref_fai ref_dict filter_clip duplex_metrics mosdepth fragment_stats vardict filter_vcf background_polish norm_truth truth_in_normals genotype_truth benchmark summarise multiqc"
snakemake --profile profiles/local -n --allowed-rules $ALLOWED
```

## Extra scripts

- `scripts/pretty_rulegraph.py`: stage-grouped rule graph, `snakemake --rulegraph | python scripts/pretty_rulegraph.py | dot -Tsvg > rulegraph.svg`
- `scripts/idt_vendor_benchmark.sh`: lifts over (if hg19), normalises and scores the SEQC2 published IDT call sets (figshare 10.6084/m9.figshare.13412246) with the same truth set and panel. Those call sets stop at 2% VAF and report the Accugenomics spike-ins, so compare at AF >= 2% with spike-in sites excluded.
- `scripts/make_slide_figures.py`: slide figures from `results/benchmark/`

## References behind the additions

- Newman et al. 2016, Nat Biotechnol: integrated digital error suppression (iDES) - duplex UMIs plus background polishing.
- Wan et al. 2020, Sci Transl Med: INVAR - integration of variant reads across loci, locus-specific error rates, fragment-size weighting.
- Reinert et al. 2019, JAMA Oncol: ultradeep sequencing of 16 patient-specific variants in stage I-III CRC; ≥2 detected variants = ctDNA positive.
- Annals of Oncology 2024 review of MRD in CRC: tumour-informed vs tumour-agnostic strategies.

## Benchmark subset used for the SEQC2 IDT data

The IDT panel has no 1:124 dilution (Sample F) or AcroMetrix (AC01) libraries, so the default `config/samples.tsv` uses:

- SampleEfIS (1:24, 4% Sample A), 3 replicates: low-VAF sensitivity and PPV
- SampleDfIS (1:4, 20% Sample A), 2 replicates: extends the VAF range upward
- SampleBfIS LIB3 (background only, `vaf_scale 0`): held-out negative control
- SampleBfIS LIB1-2: panel of normals for background polishing
